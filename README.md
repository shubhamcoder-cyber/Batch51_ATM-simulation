# 🏧 ATM Simulation System

## 📌 Project Overview

ATM Simulation System is a C programming mini-hackathon project designed to simulate basic ATM banking operations for a single demonstration account.

This project demonstrates the use of **functions, loops, conditional statements, switch-case, and user input handling in C programming**.

## ✨ Features

- Check Account Balance
- Deposit Money
- Withdraw Money
- Reject Invalid Transaction Amounts
- Prevent Withdrawal if Balance is Insufficient
- Display Updated Balance After Transactions
- Exit the ATM System
